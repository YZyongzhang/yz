# numpy 计算角度
技术的起因是因为我在约束agent前进的方向的时候需要对agent的角度进行约束。这样的话就需要求出三个点之间的夹角
### 错误思考
最初我曾经想过余弦定理，也就是三角形的三条边然后求出角度，但是我忽略了一个十分重要的点就是，其实三角形的余弦定理也是通过向量推算出来的。
### 正确做法
numpy是一个科学计算库，这个没有什么问题。那我们如何使用向量呢？首先我们要知道向量有点乘和叉乘两种运算。ok，我们首先要明白一个前提就是我们想要计算的点都是拥有坐标的，也就是在一个坐标系中拥有了坐标。那么我们就可以将这个坐标理解为从原点到该点的向量。然后我们使用向量的减法，就能求出任意两点的向量。<br>
ok ， 现在我们要开始计算角度了。我们现在需要明确两种运算，也就是我上文中描述的叉乘和点乘。首先我们来解释什么是点乘，这种运算就是求出的是一个向量在另一个向量中的投影。a向量的模*b向量的模 * 两者之间的夹角cos值。当我们将a向量和b向量都转化为单位向量的时候，我们就可以之间通过叉乘然后得到cos值从而推出角度了。<br>
代码描述
```
import numpy as np
a = np.array([1,0,0])
b = np.array([0,0,1])
c = np.array([0,1,0])
ab = b - a
cb = b - c
# ab 和 cb 计算的就是以b为顶点的角
# cos角的计算公式
costheta = np.dot(ab , cb ) / np.linalg.norm(ab)*np.linalg.norm(cb)
theta = np.arccos(costheta) # 反三角函数
angle = np.degrees(theta)
```
